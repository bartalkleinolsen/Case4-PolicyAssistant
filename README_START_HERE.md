# Case 4 - Company Policy Assistant

Denne mappe indeholder den originale opgavebeskrivelse og policy-data (98 politikker).

## Første skridt
1. Pak ZIP-filen ud.
2. Åbn Visual Studio Code.
3. Vælg File > Open Folder og vælg selve mappen `Case4-PolicyAssistant`.
4. Kontroller, at du kan se `ASSIGNMENT.md` og mappen `data` med `company_policies.csv`.
5. Gå tilbage til ChatGPT-tråden med Case 4 for næste trin.

## Planlagt teknisk løsning
- Python/Flask som backend, så API-nøgler ikke afsløres i browseren.
- HTML/CSS/JavaScript som frontend.
- Tre søgemetoder: regelbaseret, LLM uden vector index og RAG med embeddings.
- Gemini API til LLM og embeddings.
- GitHub til kildekode; online hosting til webappen.
- Slack bot med Socket Mode, som kan køre lokalt.

Sikkerhed: Ingen ægte API-nøgler eller Slack-tokens må gemmes i GitHub.
